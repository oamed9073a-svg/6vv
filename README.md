# Змейка

Классическая игра «Змейка» в одном HTML-файле.

## Запуск

Откройте `index.html` в любом современном браузере — никакой сборки не требуется.

## Управление

- **Стрелки** или **WASD** — движение
- **Пробел** — пауза
- На сенсорных экранах — свайпы

## Особенности

- Плавная анимация и градиентная отрисовка
- Подсчёт счёта и сохранение рекорда в `localStorage`
- Увеличение скорости по мере поедания еды
- Поддержка мыши, клавиатуры и тача
