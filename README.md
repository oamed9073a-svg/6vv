# Змейка 🐍

Классическая аркадная «Змейка» в одном HTML-файле — без сборки и зависимостей.

## Как запустить

Просто открой `index.html` в браузере.

## Управление

- Стрелки или `WASD` — поворот
- `Space` — пауза
- `R` — новая игра
- На сенсорных экранах — кнопки на экране или свайпы

## Особенности

- Плавное движение со постепенным ускорением при росте счёта
- Сохранение рекорда в `localStorage`
- Адаптивный интерфейс с поддержкой мобильных
- Без зависимостей — один файл
