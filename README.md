# Выживание в лесу

Игра про выживание в глухом лесу. Доступна в двух вариантах:

- **Браузерная** — `index.html`, чистый HTML/CSS/JS, без зависимостей.
- **Python/pygame** — `forest_survival.py`.

## Браузерная версия

Открой `index.html` в любом современном браузере и нажми **НАЧАТЬ**.

## Python версия

```bash
pip install pygame
python forest_survival.py
```

Затем нажми **ПРОБЕЛ** на стартовом экране.

### Управление

| Клавиша | Действие |
|---|---|
| `WASD` / `←↑↓→` | Движение |
| `Space` | Действие — рубить дерево / добывать камень / собирать ягоды / атаковать волка |
| `E` | Поесть (ягоды или жареное мясо, если рядом горит костёр) |
| `R` | Пить воду из реки (нужно стоять у берега) |
| `F` | Развести костёр (3 дерева + 2 камня) или подкинуть в него дров |
| `T` | Спать у костра (восстанавливает энергию и здоровье, ускоряет время) |

### Что нужно знать

- Следи за **здоровьем**, **голодом**, **жаждой** и **энергией** — если хоть один параметр упадёт до нуля, ты начнёшь терять здоровье.
- **Ночью** становится холодно. Без костра рядом ты будешь мёрзнуть и терять здоровье.
- **Волки** приходят с темнотой. Они боятся костра, поэтому держись поближе к огню.
- **Мясо** нужно жарить — есть сырым нельзя. Жарь у костра.
- С каждым днём волки становятся **сильнее и многочисленнее**. Долго не протянешь, но попробуй прожить как можно больше дней.

Удачи!
