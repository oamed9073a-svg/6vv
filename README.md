# VK-бот для маникюрного салона 💅

Бот ВКонтакте для записи клиентов в маникюрный салон и управления записями
администратором. Клиенты записываются через кнопки (услуга → мастер → дата →
время → имя → телефон), администратор получает уведомления и управляет записями.

## Возможности

**Для клиентов:**
- 📅 Запись на услугу: выбор услуги, мастера, даты и свободного времени
- Свободные слоты рассчитываются с учётом длительности услуги и уже занятого времени мастера
- 📋 Просмотр своих записей и их отмена
- ℹ️ Список услуг и цен

**Для администратора:**
- 🔔 Мгновенные уведомления о новых записях и отменах
- 📆 Просмотр записей на сегодня
- 🗓 Просмотр записей на любую дату
- 🗑 Отмена записи по номеру (клиент получает уведомление об отмене)

## Структура проекта

| Файл | Назначение |
|------|------------|
| `bot.py` | Точка входа, обработка сообщений и сценарии диалога |
| `config.py` | Конфигурация из переменных окружения |
| `salon.py` | Услуги, мастера, часы работы — **редактируйте под свой салон** |
| `database.py` | Хранилище записей (SQLite) и расчёт свободных слотов |
| `keyboards.py` | Клавиатуры ВК |
| `states.py` | Машина состояний диалога |

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env: укажите токен, ID сообщества и ID администраторов
```

### Где взять данные

- **VK_TOKEN** — Сообщество → *Управление* → *Работа с API* → *Ключи доступа*.
  Создайте ключ с правом **«Сообщения сообщества»**.
- **VK_GROUP_ID** — числовой ID сообщества (без минуса).
- **VK_ADMIN_IDS** — личные ID администраторов через запятую.

### Настройка сообщества

В *Управление* → *Настройки* → *Работа с API* → *Long Poll API*:
- включите Long Poll API (версия 5.131+);
- в *Типах событий* включите **«Входящие сообщения»**.

В *Сообщения* → *Настройки для бота* включите возможности бота и кнопки.

## Запуск

```bash
python bot.py
```

Бот работает через Bots Long Poll API — внешний веб-сервер не нужен.

## Настройка под салон

Откройте `salon.py` и измените:
- `SERVICES` — список услуг (название, цена, длительность в минутах);
- `MASTERS` — список мастеров;
- `WORK_START_HOUR` / `WORK_END_HOUR` — часы работы;
- `SLOT_STEP_MIN` — шаг сетки записи;
- `BOOKING_DAYS_AHEAD` — на сколько дней вперёд открыта запись.
